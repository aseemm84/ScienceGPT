# ScienceGPT v2 — AI-Powered Science Learning Tool

An interactive science tutoring platform for Indian students in Grades 1–12, following the NCERT curriculum. Powered by Groq (LLaMA 3.1) for AI responses and YouTube Data API for video recommendations.

---

## 🚀 Setup

### 1. Clone and install

```bash
git clone https://github.com/your-repo/sciencegpt.git
cd sciencegpt
pip install -r requirements.txt
```

### 2. Configure API keys

```bash
cp .streamlit/secrets.toml.template .streamlit/secrets.toml
# Edit secrets.toml and add your keys
```

Required keys:
- `GROQ_API_KEY` — from [console.groq.com](https://console.groq.com) (free tier available)
- `YOUTUBE_API_KEY` — from [Google Cloud Console](https://console.cloud.google.com) (YouTube Data API v3, free quota: 10,000 units/day)

### 3. Run

```bash
streamlit run app.py
```

## 🎮 Feature Guide

### Streaming Responses
Answers appear word-by-word as Claude generates them. No more waiting for a full response before seeing anything.

### Quiz Mode (📝 Quiz tab)
1. Select your Grade, Subject, and Topic in the sidebar
2. Click the **Quiz** tab
3. Click **Generate Quiz** — 5 questions appear (3 MCQ + 1 True/False + 1 Short Answer)
4. Answer all questions and click **Submit Quiz**
5. MCQ and T/F are graded instantly; short answers are graded by Claude
6. Results update your Mastery Map automatically

### Socratic Mode (🦉)
Toggle **Socratic Mode** in the sidebar. Claude will ask guiding questions instead of giving direct answers. After 3 exchanges on the same concept, the answer is revealed. Earn the "Socratic Scholar" badge after 5 sessions.

### Explain It Back (🗣️)
After every assistant response, an **"Explain It Back"** panel appears. Type your understanding in your own words — Claude scores it 1-10 and tells you exactly what you got right and what was missing. Scores ≥7 earn bonus points.

### Mastery Heatmap (📊 My Progress tab)
A colour-coded grid showing every topic in your current subject:
- ⬜ **Grey** — never attempted
- 🟥 **Red** — avg quiz score < 40%
- 🟨 **Amber** — avg quiz score 40-69%
- 🟩 **Green** — avg quiz score ≥ 70%

### At-Home Experiments (🧪)
In the right panel, click **"Suggest an Experiment"** for a safe, household-item experiment tied to your current topic.

## ⚙️ Technical Notes

- **LLM:** Groq API, `llama-3.1-8b-instant` model. Fast, free tier available.
- **Streaming:** Uses Groq's `stream=True` parameter, piped into `st.write_stream()`.
- **Caching:** `@st.cache_resource` for `LLMHandler` and `CurriculumData` singletons. LLM responses cached per settings hash in `st.session_state`.
- **Translation:** `deep-translator` (GoogleTranslator). Original English response preserved and shown in expander.
- **Progress:** Session-based only — resets on browser refresh. Future work: add a database backend.
- **Plotly:** Used for mastery heatmap and weekly activity chart. Falls back gracefully to text if not installed.

---

## 🐛 Known Limitations

- Progress resets on browser refresh (session state only, no database)
- Free Groq API has rate limits (token/min and requests/day)
- YouTube search requires an active internet connection
- Translation quality depends on Google Translate availability
